# User Manual

This manual describes features present in SHIBLI C2 v1.0.

## Sign in

1. Start **SHIBLI C2**.
2. Choose **LAN** or **IP / Online**.
3. Enter your SHIBLI username and password.
4. Select **LOGIN**.

Use **Forgot password?** only if an administrator has configured a recovery code for this site.

## Dashboard

The dashboard shows live Day and Thermal video when cameras are configured and reachable.

- **Day** and **Thermal** panels display the selected streams.
- Drag a box on a live panel to zoom that region.
- Camera status is shown on the dashboard.

## PTZ and lens

When your role allows hardware control:

- Pan and tilt from the PTZ pad
- **Zoom + / Zoom −**
- **Focus + / Focus −**
- **AFC** holds auto-focus on the selected channel
- Speed: Low / Med / High

## Presets

Use the preset list to **Set**, **Go**, or **Delete** a numbered preset on the active PTZ.

## Recording and snapshots

- **Off / Day / Thermal / Both** starts or stops live recording.
- Open **Recordings** to list, play, and export stored clips.
- Snapshots are stored in the site snapshots folder.

## LRF and illuminator

- **LRF** takes a range measurement when the device is connected.
- Illuminator controls set on/off, source, beam, and brightness when the hardware is present.

## Auxiliaries

**Wiper** and **Heater** send auxiliary commands when the connected device supports them.

## Cameras page (Administrator)

Administrators add and edit cameras, including name, type (Day / Thermal), connection type (LAN / IP / Online / Unassigned), host, RTSP, ONVIF, and PTZ mapping.

Camera usernames and passwords are device credentials. They are not your SHIBLI login.

## Users page (Administrator)

Create and manage SHIBLI users and roles. This never changes camera passwords.

## Settings and audit

Administrators can adjust site settings and review the audit log.

## Sign out

Use **Logout**. The next person must sign in again.
