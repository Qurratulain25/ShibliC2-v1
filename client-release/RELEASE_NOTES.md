# SHIBLI C2 v1.0 Release Notes

SHIBLI C2 v1.0 is the first client desktop release.

## Highlights

- Desktop application window (no browser required)
- LAN and IP / Online connection modes
- Day and Thermal camera operation
- PTZ, zoom, and focus controls
- Presets
- Region zoom on live video (drag a box)
- Recording and playback
- Snapshots
- LRF and illuminator controls
- Wiper and heater auxiliaries where the device supports them
- Local authentication with roles (Administrator, Operator, Viewer)
- Offline Windows and Ubuntu installers

## Installation

Download one file from Releases and install it. No extra components are downloaded during or after setup.

## Notes

- Fresh installs ask you to create the first Administrator. There is no factory password.
- Existing cameras stay visible in both modes until an administrator assigns LAN or IP / Online.
- Uninstalling the application does not delete recordings or the site database.
